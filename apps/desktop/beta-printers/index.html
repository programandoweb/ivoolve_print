Impresoras BETA

Configura las impresoras de esta estación y elige si deseas imprimir etiquetas con o sin diálogo Windows.

Modo de impresión de etiquetas

Desmarcado: se muestra el selector Windows habitual. Marcado: se envían las etiquetas directamente al perfil elegido, incluidos trabajos recibidos mientras esta aplicación está abierta. Si la impresora es ambigua o no está disponible, se detiene el envío. Sin serial físico, verifica el equipo antes de activar este modo.

Impresoras instaladas

Sin serial físico fiable la coincidencia es probable. Dos equipos iguales son ambiguos: verifique con Windows y vuelva a vincular. No se reasignan perfiles automáticamente.
